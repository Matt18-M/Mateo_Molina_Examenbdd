Este proyecto corresponde al examen práctico del taller de desarrollo backend.

En esta parte se desarrolló una API REST utilizando Spring Boot para gestionar la entidad Vuelo.

GET: Listar y buscar por ID
PUT: Actualizar
DELETE: Eliminar
